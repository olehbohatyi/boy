# boy

A personal package manager for prebuilt binaries.

```sh
curl -fsSL https://github.com/olehbohatyi/boy/raw/main/install.sh | sh
```

```
boy i <name>[@version]  install
boy r <name>            remove
boy l                   list installed
boy s [query]           search
boy u [name]            update
```

Status: early development. See [docs/prd.md](docs/prd.md).
